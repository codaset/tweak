Loaded from another folder

Chrome loads this copy of Codaset Tweak from somewhere other than the folder Tweak keeps up to date, so it can't update itself. Remove it in chrome://extensions and load ~/.local/state/codaset-tweak/extension.

Point Claude at the exact template

This Rails app doesn't mark which template renders what, so Tweak can only give Claude search clues. To name the template, uncomment this line in config/environments/development.rb and restart the server:

config.action_view.annotate_rendered_view_with_filenames = true
