# Codaset Tweak

Point at any element of your running web app in Chrome, describe a tweak, and the Claude Code
session that claimed the page makes the change. You follow it in a card pinned to the element,
and you can undo it. It works with any web app, without changes to the app.

This plugin provides the `/tweak` skill, the `tweak` command and the hooks that record changes
for Undo. The Chrome extension comes with the `tweak` binary. See https://github.com/codaset/tweak.
